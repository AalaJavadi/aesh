AESH 5.0 — بسته اصلاحات غیرمرتبط با Supabase (مرحله دوم)
تاریخ: ۲۶ اکتبر ۲۰۲۶
مخزن هدف: AalaJavadi/aesh ، شاخه main

این یک PATCH است، نه ZIP کامل سایت. فقط ۲۱ فایل موجود را جایگزین می‌کند.
هیچ نمونه‌کار، تصویر، داده کاربر، فایل SQL، مخزن Storage یا Workflow حذف و عوض نمی‌شود.

نصب ساده:
۱) قبل از تغییر، از پوشه مخزن GitHub Desktop یک نسخه پشتیبان بگیرید.
۲) این ZIP را Extract All کنید و فقط محتویات پوشه‌های assets، members،
   editor، tools، teacher و student را روی پوشه هم‌نام در مخزن کپی و Replace کنید.
   فایل‌های اضافی مخزن را DELETE نکنید. خودِ فایل ZIP را در GitHub آپلود نکنید.
۳) در GitHub Desktop: Commit to main و Push origin.
۴) در GitHub Actions نتیجه Build و Deploy را ببینید؛ بعد سایت را با Ctrl+Shift+R باز کنید.

تغییرات:
- ویرایشگر: handshake راه‌اندازی iframe، مسیر میانبر صفحه Studio، حالت اولین رمز محلی.
- گالری: جلوگیری از نمایش آثار قدیمی و جابه‌جایی ناگهانی پیش از پاسخ RPC؛
  حفظ آثار قدیمی در صورت قطع ارتباط.
- تصاویر شاخص: هشت پروفایل قدیمی به‌جای آیکون سایت تصویر اجتماعی مناسب دارند؛
  ویرایشگر هنگام خروجی ZIP برای تصاویر نسبی هم OpenGraph درست می‌سازد.
- پروفایل‌های جدید: رفع نام اشتباه image_path در فهرست و ژنراتور HTML،
  اطلاعات تخصصی اختیاری از فیلد extra JSONB موجود، محافظت از لینک‌های عمومی.
- سئو: ابزار staging برای پروفایل‌های بدون عکس، تصویر شاخص تعیین می‌کند؛
  Sitemap و Canonical آثار Cloud حفظ شده‌اند و دست‌کاری نشده‌اند.

محدودیت‌های مهم:
- این بسته SQL لازم ندارد، اما توابع/جدول‌های واقعی دایرکتوری و نظرات
  در صورت نبودن در Supabase همچنان کار نمی‌کنند.
- ساخت حساب ورود واقعی از پنل مدیر نیازمند Backend/Edge Function امن است؛
  این بسته حساب کاربری نمی‌سازد.
- آپلود اثر در صورت work_buckets_are_private=false هنوز توسط کنترل امنیتی
  درست متوقف می‌شود. برای رفع آن باید Storage/RLS در محیط آزمایشی بررسی شود.
- ایندکس واقعی گوگل، حتی با HTML و Sitemap درست، تضمین نمی‌شود.
- آزمون‌های این بسته آفلاین هستند؛ قبل از ارسال عمومی، GitHub Actions را کنترل کنید.
