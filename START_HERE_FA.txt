مهم:
۱) اگر همین نسخه قبلاً در GitHub main آپلود شده، دوباره آپلود کردن هیچ تغییری در
   سایت ایجاد نمی‌کند. آخرین GitHub Build مشاهده‌شده سبز بود، اما Deploy نبود.
۲) GitHub با آپلود مستقیم فایل ZIP آن را Extract نمی‌کند. فقط پس از گرفتن بکاپ
   مخزن، محتوای ZIP را از طریق GitHub Desktop داخل پوشهٔ مخزن کپی و Commit/Push کن؛
   پوشهٔ .github را نیز حفظ کن. هیچ فایل قدیمی/هنری را دستی پاک نکن.
۳) انتشار سایت اصلی با یک Build سبز انجام نمی‌شود. Workflow اختصاصی Production
   نیازمند تأیید جداگانه است و تا آن زمان به‌عمد منتشر نمی‌کند.
۴) آخرین بررسی SQL کاربر: جدول public.aesh_directory_profiles و تابع
   public.aesh_public_directory() در Supabase اصلی وجود نداشتند.
   برای انتشار واقعیِ ایمن، باید پیش‌نیازهای دیتابیس و امنیت Storage/Edge
   روی محیط جداگانه آزمایش و سپس با بکاپ و تأیید روی Production اعمال شوند.
۵) این ZIP هیچ SQL اجرا نمی‌کند، هیچ داده‌ای از Supabase حذف/تغییر نمی‌دهد،
   و فعال‌سازی Production را دور نمی‌زند.
