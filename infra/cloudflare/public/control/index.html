مشاهده پنل اعضا

ساخت سایت فقط بعد از فعال‌سازی امن و تأیید مدیر انجام می‌شود؛ درخواست لزوماً به معنای انتشار موفق نیست.

برای انتشار صفحات عمومی، بعد از تأیید باید فرایند ساخت GitHub Pages با اتصال امن به CMS فعال و تست شود.

دسترسی حساب‌ها

این فرم سطح دسترسی هویت Cloudflare Access را مدیریت می‌کند؛ حساب و رمز عبور Supabase را تغییر نمی‌دهد و دعوت‌نامه ایمیلی ارسال نمی‌کند.

دعوت امن با ایمیل تأییدشده Cloudflare Access

پس از ساخت پروفایل و تأیید هویت واقعی فرد، ایمیل او را دعوت کنید. رمز قبلی Supabase انتقال نمی‌یابد؛ این پنل ایمیل نمی‌فرستد و لینک ورود را باید خودتان برای فرد ارسال کنید.
